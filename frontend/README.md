# NammaSahay AI - Frontend

Tamil-first AI assistant for understanding Tamil Nadu government schemes and public services.

## Technology Stack
- **Framework:** React 18 + TypeScript + Vite
- **Icons:** Lucide React
- **Styling:** Vanilla CSS (Custom Civic-Tech Design System)

## Prerequisites
- Node.js (v18+)
- Backend API running on `http://127.0.0.1:8000`

## Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

The app will start at `http://localhost:3000`.

### 3. Build for Production
```bash
npm run build
```
